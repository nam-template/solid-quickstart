# Feature Spec — 지붕 낚시 (Roof Fishing)

> **소속:** SAFE HOUSE (dark-war-ad-gdd.md) · 손 뻗기 MVP **1순위 확정**
> **한 줄:** 전쟁통에 캠핑카 지붕에서 태평하게 낚시. 수몰 도시의 물에서 물자·물고기·사연을 건짐.
> **버전:** 0.1 (draft) · **작성일:** _____

---

## 1. 역할 & 판타지
- **역할:** 게임의 **주력 물자 확보 경로**. "손 뻗기"(밖에 안 나가고 밖과 상호작용) 긴장의 핵심.
- **판타지:** 세상은 무너졌는데 나는 지붕 위에서 낚싯대를 드리운다 → **이 게임의 시그니처 장면 = 광고의 괴리감 그 자체**
- **감정 리듬:** 밖(전쟁·회색)의 씁쓸함 → 낚는 순간의 작은 설렘 → 방으로 돌아와 아늑하게 가공

## 2. 무대: 왜 물이 있나 (확정 후보)
- **수몰된 폐허 도시** (추천) — 캠핑카가 고지대/옥상에 정박, 아래는 물에 잠긴 건물들.
  - 수면 사이로 잠긴 간판·신호등·지붕이 보임 / 물에 화염·연기 반사 / 멀리 전쟁
  - "떠내려오는 물자"에 개연성 (물살에 실려 옴)
- 대안: 강가 캠프 / 해안. → 결정 필요: _____

## 3. 무엇을 낚나 (Catch Table — 카테고리)
| 분류 | 예시 | 용도 |
|------|------|------|
| 🐟 식량 | 물고기, 통조림, (변이) 큰 물고기 | 식량 게이지 보충 |
| 🪵 폐품/재료 | 떠내려온 목재·천·금속, 탄피, 낙하산 조각 | 가구 제작 재료 |
| 📦 희귀 | 군용 보급상자, 특별 가구 부품, 도면 | 확장·레시피 해금 |
| 💌 서사 | 편지, 사진, 낡은 인형, 라디오 부품 | 조용한 스토리 (선택) |
| 🥾 꽝/유머 | 낡은 장화, 쓰레기, 물 먹은 신문 | 소소한 웃음·환경 |

- 확률 테이블은 **시간대/날씨/장비**로 변동 (아래 6번)

## 4. 뷰 & 연출 (하드컷 전환)
- 실내 뷰 → [지붕으로] → **낚시 뷰(측면)**: 캠핑카 지붕 + 소녀 + 낚싯줄 + 수면 + 창밖 전쟁 배경
- 도트 연출: 수면 반짝임·물결, 찌 흔들림, 물에 비친 화염, 멀리 연기, 라디오 지직
- 잡는 순간: 시그니처 사운드 + 짧은 획득 팝업(아이템 도트)

## 5. 코어 인터랙션 (한 사이클)
```
[캐스팅] → [대기/입질] → [챔질 타이밍] → [릴링(텐션 관리)] → [획득]
```
1. **캐스팅:** 던질 위치/거리 선택 (원거리=희귀 확률↑, 난이도↑)
2. **대기/입질:** 찌가 흔들리다 쑥 들어가는 순간
3. **챔질:** 입질 타이밍에 반응 (놓치면 미끼만 뺏김)
4. **릴링:** 라인 텐션 미니게임 — 너무 세게 당기면 **줄 끊김**, 너무 약하면 **놓침**. 적정선 유지
5. **획득:** catch table에서 결과 → 인벤토리

- **조작 톤:** 하드코어 액션 아님. *캐주얼 타이밍* (한 손으로 편하게). 정밀도보단 리듬감

## 6. 긴장 설계 (몸이 아니라 '물자·기회'를 향함 — 기둥 1 준수)
- **자원 제한:** 하루 캐스팅 횟수 or 미끼 소모 → 매 캐스팅이 의미있음
- **실패 = 손실이지 사망 아님:** 줄 끊김 → 미끼/잡은 것 잃음. 처벌적 리셋 없음
- **날씨/시간대:** 비 오는 밤엔 희귀 확률↑ 대신 릴링 난이도↑ 같은 트레이드오프
- **떠내려가는 기회:** 가끔 화면에 **희귀 보급상자**가 물살에 떠내려옴 → 지금 안 잡으면 사라짐 (소프트 FOMO)
- 튜닝 원칙: **"불편함이지 위험 아님"** — 못 잡으면 이번 주가 좀 삭막할 뿐

## 7. 진행 & 성장
- **장비 업그레이드(폐품으로 제작):** 낚싯대·릴·낚싯줄·미끼 → 더 멀리/더 희귀/덜 끊김
- **미끼 종류:** 미끼에 따라 catch table 편향 (식량용 vs 폐품용 vs 희귀용)
- 성장 → 확장(새 정박지/더 깊은 물) → 새 catch table 해금

## 8. Core Loop 연결
```
[지붕 낚시] → [식량/폐품/희귀 확보] → [작업대 제작·식량 보충] → [방 꾸미기·확장]
     ▲                                                              │
     └──────────  더 좋은 장비·미끼·정박지 해금  ◀────────────────────┘
```

## 9. 전쟁 향 디테일 (몰입용 소품)
- 수면에 뜬 잔해·기름띠, 물에 비친 화염, 잠긴 도시의 실루엣
- 낚이는 군용품(탄약상자·철모), 물 먹은 전단지·징집 포스터
- 라디오에서 흘러나오는 전황 뉴스 (낚시 BGM 위에 얹힘)

## 10. MVP 스코프
### In
- 캐스팅→입질→챔질→릴링→획득 **1사이클** 동작
- catch table 최소 3분류(식량·폐품·희귀) + 아이템 소수
- 텐션 릴링 미니게임 1종
- 폐품→제작 / 식량→게이지 연결
- 낚시 뷰 도트 1장 + 잡는 연출

### Out (나중)
- 미끼/장비 풀 업그레이드 트리, 서사 아이템, 날씨 변동 테이블, 다중 정박지, 도감

## 11. 오픈 이슈 (정할 것)
1. **물의 정체:** 수몰 도시(추천) vs 강 vs 해안
2. **릴링 방식:** 실시간 텐션바 vs 캐주얼 타이밍탭 vs QTE — 톤에 맞는 건?
3. **자원 제한 방식:** 캐스팅 횟수 vs 미끼 소모 vs 무제한(코지 우선)
4. **긴장 강도:** 줄 끊김 페널티를 얼마나 (거의 없음 ↔ 미끼+잡은 것 손실)
5. 서사 아이템(편지·사진)으로 스토리를 넣을지

## 12. 마일스톤 (M0~M1 낚시 파트)
| 단계 | 산출물 | 목표 |
|------|--------|------|
| F0 | 캐스팅+릴링 프로토(도형으로) | 낚는 손맛 확인 |
| F1 | catch table + 획득→인벤토리 | "얻는 재미" |
| F2 | 낚시 뷰 도트 + 사운드 + 전쟁 배경 | 괴리감 체감 |
| F3 | 폐품→제작→꾸미기 연결 | 루프 한 바퀴 |
