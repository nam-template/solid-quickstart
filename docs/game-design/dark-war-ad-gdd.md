# 게임 기획서 (경량 GDD) — "광고 그대로의 서바이벌" (코드네임: TRUE-AD)

> **콘셉트:** 다크워: 서바이벌의 *광고*가 약속했지만 실제 게임엔 없던 그 경험을 진짜 게임으로.
> **형식:** 경량 GDD (독립 게임) · **아트:** 도트/픽셀 · **버디 연동:** 보류(나중)
> **작성일:** _____ · **작성자:** _____ · **버전:** 0.1 (draft)

---

## 0. 한 줄 피치 (Elevator Pitch)

> "그 광고, 진짜였다." — 좀비 아포칼립스에서 생존자를 **핀뽑기 퍼즐로 구출**하고,
> 폐허가 된 은신처를 **재건·꾸미고**, 공동체를 키우며 좀비를 막아내는 도트 서바이벌.

- 후크(왜 사람들이 클릭하나): 이미 **수억 뷰로 검증된 광고 판타지**를 실제로 충족 → 마케팅 훅이 게임에 내장됨
- 밈/바이럴 각도: "낚시 광고를 진짜로 만들어봤다"는 것 자체가 콘텐츠

---

## 1. 디자인 기둥 (Design Pillars) — 흔들리면 안 되는 것 3개

1. **광고를 배신하지 않는다** — 광고에서 본 순간(구출·재건·방어)이 실제로 게임에 있다
2. **한 명을 살렸다는 감정** — 숫자가 아니라 캐릭터. 구한 생존자에게 애착이 생겨야 함
3. **폐허 → 보금자리** — 내 손으로 되살아나는 공간의 만족감 (님의 꾸미기+확장 핵심)

## 3. 핵심 게임 요소 (광고의 6요소 → 게임 시스템)

### 3-A. 핀뽑기 구출 퍼즐 ⭐ (시그니처)
- 갇힌 생존자를 살리려 **핀/장애물을 올바른 순서로** 제거 (물·용암·바위·좀비 활용)
- 실패 = 생존자 사망(또는 재시도). 성공 = 그 생존자가 **은신처 합류**
- 난이도 곡선: 초반 2~3핀 → 후반 다단계/함정
- MVP 퍼즐 수: ___개

### 3-B. 은신처 재건 + 꾸미기 (님의 원래 콘셉트)
- 폐허 상태에서 시작 → **청소 → 수리 → 가구 배치 → 확장**
- 도트 격자 배치 (아이소 아님, 정면/탑다운 중 택: _____)
- 확장 단계: 방 1칸 → ___ → ___ (구출한 생존자 수/자원으로 해금)
- 기능성 오브젝트: 침대(생존자 휴식), 농장(식량), 작업대(제작) 등

### 3-C. 생존자 관리
- 구출한 생존자에게 **역할** 부여 (요리·수리·방어·수색)
- 각자 이름/성격/작은 사연 → 애착 (기둥 2)
- 욕구 관리: 식량/물/사기 (가볍게)

### 3-D. 좀비 방어
- 주기적 습격 → 배치한 방어시설/생존자로 막음
- 형태 택1: (a) 간단 타워디펜스 / (b) 자동전투 / (c) 미니 액션 → _____
- 방어 결과가 은신처/생존자에 영향

### 3-E. 자원 수집 & 선택지
- 밖으로 **수색(스캐빈지)** → 자원·새 생존자·위험 이벤트
- **도덕적 선택지** (누구를 구할까 / 자원을 나눌까) → 서사 몰입

---

## 4. Core Loop

```
[수색·탐험] → [생존자 구출 퍼즐] → [은신처 재건/꾸미기] → [생존자 배치·성장]
     ▲                                                          │
     │                    [좀비 습격 방어]  ◀────────────────────┤
     └──────────────  자원·인구·새 지역 해금  ◀───────────────────┘
```

- 한 사이클 목표 시간: ___분
- 세션당 감정 곡선: 긴장(구출/방어) → 안도(재건/꾸미기) 반복

---

## 5. 진행 & 확장 (Progression)

- **거시 목표:** 폐허 은신처 → 번성하는 공동체 (엔딩/장기 목표: _____)
- **해금 축:** 인구 ↑ → 방 확장 → 새 지역 수색 → 더 어려운 구출/방어
- **재화:** 식량·자재 (초기 2종 권장) / 인구 자체가 핵심 자원
- 이탈 방지: 매 세션 "새 생존자 한 명 구함" 같은 **작은 승리** 보장

## 6. 아트 & 사운드 (도트)

- **픽셀 해상도/스케일:** _____ (예: 32x32 타일, 캐릭터 16x24)
- **팔레트:** 종말 회색톤 + 재건될수록 색이 돌아옴 (상태를 색으로 표현)
- **애니메이션 우선순위:** 구출 순간 · 생존자 일상 행동 · 좀비 습격
- **사운드:** 긴장/안도 대비 BGM, 구출 성공 시그니처 사운드

## 7. 스코프 — MVP (버티컬 슬라이스)

### In (수직 슬라이스에 반드시)
- 핀뽑기 구출 퍼즐 ___개 + 성공→합류 연결
- 은신처 1구역 재건/배치 + 확장 1단계
- 생존자 2~3명 관리
- 좀비 습격 1종 방어
- → **"광고의 핵심 한 바퀴"가 실제로 돌아가는 것**

### Out (나중에)
- 대규모 지도/다수 지역
- 깊은 제작 트리, 스킬트리
- 수익화, 소셜, 버디 연동
- 다중 엔딩/방대한 서사
