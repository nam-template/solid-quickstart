## 0. 한 줄 요약 (Elevator Pitch)

> 데스크탑 버디가 "사는 방"을 아이소메트릭 큐브로 꾸미고, 재화를 모아 공간을 확장하는 기능.

- 이 기능이 존재하는 이유(가설): _____
  - 예) "버디에 '집'이라는 맥락을 주면 애착·리텐션이 올라간다"

## 1. 목표 & 성공 기준 (실험이므로 여기가 핵심)

### 검증하려는 가설
- [ ] 유저가 방 꾸미기에 **자발적으로 시간을 쓴다**
- [ ] 방/버디에 대한 **애착·재방문**이 늘어난다
- [ ] "확장하고 싶다"는 **진행 동기**가 생긴다

### 측정 지표 (하나 이상 숫자로)
| 지표 | 목표값 | 측정 방법 |
|------|--------|-----------|
| 기능 진입률 | ___% | 버디 사용자 중 방을 연 비율 |
| 1회 세션 편집 시간 | ___분 | 배치/이동 인터랙션 시간 |
| 재방문율 (D1/D7) | ___% | 방을 다시 여는 비율 |
| 첫 확장 도달률 | ___% | 첫 확장 언락까지 도달한 유저 |

### 스핀오프 결정 게이트 (Go / No-Go)
- **Go (독립 게임 검토):** 위 지표가 ___ 이상 + 확장 반복이 관찰됨
- **Keep (버디 기능 유지):** 반응은 있으나 메인급은 아님
- **Kill (제거/축소):** 진입률·재방문 모두 낮음

      └──────────────  버디 반응/보상  ◀─────────────────┘

## 4. 버디 통합 포인트 ⭐ (이 콘셉트의 최대 무기)

> 방을 "버디의 UI 배경"이 아니라 **버디가 사는 공간**으로 만들면 시너지가 폭발함.

- [ ] 버디가 배치된 가구를 **실제로 사용**한다 (침대에서 잠, 의자에 앉음)
- [ ] 방 상태가 버디 **기분/상태에 영향** (꾸며진 방 = 행복도 ↑)
- [ ] 재화 일부를 **버디 상호작용**으로 획득 (선물/놀아주기)
- [ ] 확장 시 버디의 **새 행동·애니메이션** 해금
- 통합 깊이(MVP 선택): (a) 배경만 / (b) 반응 / **(c) 상호작용** ← 시너지 위해 최소 (b) 권장
