# 10주차 실전문제 — 원간섭기와 고려말

> **여성구 교수 중간고사 스타일**(4지선다·긴 리드 지문·함정 선지)로 재구성. 총 15문제, 각 1점.

### 문제

**1.** 원 간섭기에는 원에 빌붙어 권세를 누리며 민족을 배신한 세력이 나타났다. 이는 뒷날 일제강점기의 친일파·부일배(附日輩)에 견줄 수 있다. 이처럼 원에 아부하여 반민족 행위를 일삼은 세력을 이르는 말은? ( )
　① 척화파　② 부원배(附元輩)　③ 위정척사파　④ 향리층

**2.** 입성책동(立省策動)은 고려에 원의 행성(行省)을 세워 직속령으로 삼으려던 시도로, 비유하면 일제강점기의 조선총독부 설치와 같다. 네 차례의 입성책동 중, 이제현이 원 승상 배주(拜住)에게 반대 논리를 펴 저지시킨 것은 몇 차인가? ( )
　① 제1차(1309)　② 제2차(1323)　③ 제3차(1330)　④ 제4차(1343)

**3.** 다음 ㉮에 들어갈 말로 옳은 것은? ( )
　계국대장공주의 무고 사건으로 퇴위한 충선왕은 심양왕에 봉해졌고, 1310년 이를 ㉮(으)로 고쳤다. 뒷날 그 자리는 조카 왕고(王暠)가 계승하여 고려 국왕위를 노리는 옹립운동의 불씨가 되었다.
　① 요왕　② 심왕(瀋王)　③ 제왕　④ 북원왕

**4.** 1361년 홍건적이 10만 대군으로 2차 침입하여 개경이 함락되고 만월대가 소실되었다. 이때 공민왕이 몽진(蒙塵)하여 피난한 곳은? ( )
　① 나주　② 강화　③ 안동　④ 서경

**5.** 홍건적의 침입에 대한 설명으로 옳지 <u>않은</u> 것은? ( )
　① 1차(1359)에 서경이 함락되었다.
　② 2차(1361)에 개경이 함락되고 만월대가 소실되었다.
　③ 1차 침입의 규모가 10만, 2차가 4만이었다.
　④ 2차 때 정세운·안우·이방실 등이 활약하고 이성계가 등장하였다.

**6.** 왜구 격퇴 4대첩(및 대마도 정벌)에서 전투 - 장수 - 연도의 연결이 옳지 <u>않은</u> 것은? ( )
　① 홍산대첩 - 최영 - 1376
　② 진포대첩 - 최무선 - 1380
　③ 황산대첩 - 이성계 - 1380
　④ 관음포대첩 - 박위 - 1383

**7.** 최무선이 만든 화포가 위력을 발휘하여, 1380년 충남 서천 앞바다에서 왜선을 크게 무찌른 전투는? ( )
　① 홍산대첩　② 진포대첩　③ 황산대첩　④ 관음포대첩

**8.** 다음 중 공민왕 5년(1356)의 반원 정책에 해당하지 <u>않는</u> 것은? ( )
　① 기철 일파 숙청　② 쌍성총관부 수복
　③ 정동행성 이문소 폐지　④ 변발·호복 등 몽골 풍속 폐지

**9.** 노국대장공주가 1365년 난산 끝에 사망하자, 공민왕은 개혁을 맡길 인물로 승려 출신의 한 사람을 등용하였다. 그는 전민변정도감을 통해 권문세족의 농장·노비를 정리하고 성균관을 중수하여 신진세력을 배출하였다. 이 인물은? ( )
　① 신돈　② 최영　③ 이제현　④ 정몽주

**10.** 신돈과 그의 개혁에 대한 설명으로 옳지 <u>않은</u> 것은? ( )
　① 1365년(공민왕 14) 등용되었다.
　② 1366년 전민변정도감이 설치되었다.
　③ 성균관 중수를 통해 신진세력을 길러냈다.
　④ 위화도 회군을 계기로 1388년 제거되었다.

**11.** 권문세족(권문세가)의 특징으로 옳지 <u>않은</u> 것은? ( )
　① 재추가 되어 도평의사사(도당)를 장악하였다.
　② 대농장을 경영하고 친원적 성향을 띠었다.
　③ 불교를 신봉하였다.
　④ 대체로 지방 향리층 출신으로 성리학을 수용하였다.

**12.** 원에서 주자학(성리학)을 처음 들여와 '동방의 주자'로 불리며, 백운동서원에 배향된 신진사대부의 학문적 비조(鼻祖)는? ( )
　① 안향　② 이색　③ 정도전　④ 이제현

**13.** 신진사대부의 학맥을 다음과 같이 정리할 때, ㉮에 들어갈 인물은? ( )
　안향 → ㉮ → 이제현 → 이색 → 정몽주·정도전
　① 백이정　② 길재　③ 이방원　④ 정몽주

**14.** 위화도 회군(1388) 이후의 전개로 옳지 <u>않은</u> 것은? ( )
　① 이성계가 4불가론을 내세워 회군하였다.
　② 폐가입진(廢假立眞)을 명분으로 공양왕을 옹립하였다.
　③ 1391년 과전법을 시행하였다.
　④ 회군 직후 곧바로 신돈을 제거하였다.

**15.** 고려 말 신진사대부는 온건파와 급진파(혁명파)로 분열되었다. 그 인물 분류로 옳지 <u>않은</u> 것은? ( )
　① 온건파 - 이색　② 온건파 - 정몽주
　③ 급진파 - 정도전　④ 급진파 - 정몽주

## 해설

**1. ② 부원배** — 친일파<부일배 ↔ 친원파<부원세력<부원배. 원에 붙은 반민족 세력.

**2. ② 제2차(1323)** — 유청신·오잠이 '삼한행성'을 주장하자 이제현이 원 승상 배주에게 반대해 저지. (1차=홍중희 유배, 3차=충혜왕 요청으로 중지, 4차=충혜왕 퇴위.)

**3. ② 심왕(瀋王)** — 심양왕을 1310년 심왕으로 개칭. 조카 왕고가 계승하며 심왕옹립운동의 빌미가 됨.

**4. ③ 안동** — 2차 홍건적(1361)으로 개경 함락, 공민왕 안동 몽진. (나주=거란 2차 현종, 강화=대몽항쟁, 서경=홍건적 1차 함락지.)

**5. ③** — 규모가 뒤바뀜. **1차 4만, 2차 10만**. 나머지는 옳음.

**6. ④** — 관음포대첩은 **정지(1383)**. 박위는 **대마도 정벌(1389)**의 장수. 전투-장수 짝이 틀림.

**7. ② 진포대첩** — 1380년 나세·최무선, 충남 서천. 화포 최초 실전 활용.

**8. ④** — 변발·호복 폐지는 **1352년(공민왕 1, 즉위년)** 정책. 1356년(공민왕 5)은 연호·관제 폐지, 이문소 폐지, 기철 숙청, **쌍성총관부 수복**.

**9. ① 신돈** — 1365년 등용, 전민변정도감·성균관 중수. 1371년 제거.

**10. ④** — 신돈 제거는 **1371년(공민왕 20)**. 위화도 회군(1388)은 이성계가 신돈과 무관.

**11. ④** — 향리 출신·성리학 수용은 **신진사대부**의 특징. 권문세족은 재추·도당 장악, 대농장, 친원, 불교.

**12. ① 안향** — 주자학 전래, '동방의 주자', 백운동서원 배향.

**13. ① 백이정** — 안향 → 백이정 → 이제현 → 이색 → 정몽주·정도전.

**14. ④** — 신돈 제거(1371)는 위화도 회군(1388)보다 앞선 공민왕대 사건. 회군과 무관.

**15. ④** — **정몽주는 온건파**. 급진파(혁명파)는 조준·정도전·남은.
