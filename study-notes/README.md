## 🧭 전체 흐름 잡기 (큰 그림)

### 관통하는 뼈대 — 고대국가 발전 4단계
```
성읍국가 → 소연맹국 → 연맹왕국 → 중앙집권적 귀족국가
(고조선)   (삼한)     (부여·가야)  (고구려·백제·신라)
```
> **중앙집권화의 두 지표 = 율령 반포 + 불교 공인.** 이 둘을 못 넘은 나라(부여·가야)는 멸망했다. 모든 주차를 이 틀로 꿰면 이해가 쉽습니다.

### 시간 순 한 줄 정리
- **2주차**: 식민사관 극복 + 고조선·부여 (성읍→연맹왕국)
- **3주차**: 가야(연맹왕국에서 멈춤) + 임나일본부 논쟁
- **4주차**: 고구려·백제의 중앙집권화 (소수림왕·근초고왕·성왕)
- **5주차**: 신라의 성장 + 나당동맹 → 삼국통일(676)
- **6주차**: 통일 이후 = 남북국시대(발해) + 신라 하대 호족 등장
- **7주차**: 후삼국 → 왕건의 고려 통일(936) → 호족의 향리화

### 반복되는 핵심 테마 (시험 단골)
1. **식민사관 vs 극복논리** (2주차)
2. **율령·불교공인 = 중앙집권 지표** (전 주차)
3. **왜 멸망/정체했나** — 부여·가야(율령 X), 백제·고구려(외교·내분), 궁예·견훤(패착)
4. **왕호·시대구분 변천** — 신라 왕호(거서간→왕), 신라 3대/3고, 고려 시대구분
5. **자주성 vs 사대성** 논쟁 — 임나일본부, 남북국시대론, 외왕내제
