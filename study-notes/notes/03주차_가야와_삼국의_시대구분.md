## 1. 가야의 건국과 발전
### 변한 12국 → 6가야
- 변한 12국: 철기문화 보급으로 낙동강 유역 소국들이 결집 (구야국=김해, 안야국=함안 등).
- **6가야** (건국설화: 구지봉, 42년 금알 6개 → 6동자):

| 가야 | 중심지 | 비고 |
|---|---|---|
| **금관가야** | 김해 | **전기** 가야연맹 맹주, 신라에 복속(532) |
| **대가야** | 고령 | **후기** 가야연맹 맹주, 신라에 멸망(562) |
| 고령가야 | 상주 | |
| 성산가야 | 성주 | |
| 아라가야 | 함안 | 말이산 고분군 |
| 소가야 | 고성 | 송학동 고분군 |

### 금관가야 (42~532, 10대 구형왕)
- 이름: 구야국·금관국·가락국·가라국 등. 건국설화 = 천강 + 난생(6란).
- 왕비 **허황후**: 아유타국(인도설 유력) 출신 → **남방불교** 전래(파사석탑).
- 낙동강 하구 + 김해평야 → 교역·농업 발달, 전기 맹주.

### 대가야 (후기 맹주, 고령)
- 시조 **뇌질주일(이진아고)**: 母=가야산신 정견모주, 父=천신 이비가지. 弟=금관국왕 뇌질청예(수로).
- 지산동 고분군(금동관 출토) → 강력한 정치세력 존재.

## 2. 가야 연맹의 몰락 ⭐️
### 과정
- 낙랑(313)·대방(314) 멸망 → 교역국 상실.
- 고구려(광개토왕·장수왕) 남하 + 신라 성장 + 백제 침탈.
- **532년** 신라 법흥왕 → 금관가야 병합(전기연맹 해체).
- **554년 관산성 전투**: 대가야가 백제·왜와 연합했으나 신라에 패배.
- **562년** 신라 진흥왕 → 대가야 병합 → 후기연맹 완전 몰락.

### 몰락 원인 (핵심 3가지)
1. **왕권·지배력 미약 → 율령 미반포** (중앙집권화 실패).
2. 농경 + 해양문화의 복합성 (통합 부족).
3. 신라·백제의 도전.

## 3. 가야의 후예
- **김유신**: 금관가야 마지막 왕 구형왕의 증손자(구형왕→김무력→김서현→김유신). 진골(신김씨)로 편입, 여동생 문희가 김춘추와 혼인 → **삼국통일 주역**.
- **우륵**: 대가야 가실왕이 12곡 작곡 지시. 551년 신라 진흥왕에 투항, 국원(충주)에서 음악 전수 → **가야금**.
- **강수**: 문장가. 당 고종을 감복시켜 김인문 석방. 외교문서 작성.

## 4. 임나일본부설 (任那日本府) ⭐️
> 일선동조론(타율성론)의 대표 사례. **4세기 중엽~6세기 중엽 왜가 한반도 남부를 지배했다는 주장.**

### 일본 측 근거와 반박
| 일본 측 근거 | 반박 |
|---|---|
| 『일본서기』에만 '임나일본부' 언급 | 우리·중국 사서엔 없음 |
| 광개토왕비문 "倭以辛卯年來渡海破…" | **일본군 참모본부 조작설** (변조 의혹) |
| 『송서』 왜왕 관작 기록 | **관례적 표현**일 뿐, 백제는 제외 |

### 허구성 논거
- 일본 통일국가 **야마토[大和] 정권은 6세기에야 성립** → 4세기 남한 경영은 불가능.
- 임나일본부를 뒷받침할 **유물 없음**.
- **'日本'이라는 국명은 670년경 등장** → 그 이전에 '일본부' 명칭 자체가 불가능.

### 반론(대안설)
삼한삼국분국설 / 기마민족설 / 임나백제부설 / 가야-왜 무역기구설.

## 5. 장고형고분 vs 전방후원분
- **장고형고분**: 전남 해남·함평·광주·영광·영암 등 영산강 유역, 열쇠구멍(⋈) 모양. 약 30여 기, 5세기 후반~6세기 초.
- 일본의 **전방후원분**(예: 닌토쿠 천황릉)과 형태 유사.
- 성격 논쟁: ① 왜계 백제인설 ② 백제계 왜인설 (장신구는 백제계). 지배층 무덤이라는 데는 양측 학자 일치.
- 최근엔 식민 기구가 아닌 **대외교역 사무소** 정도로 비정하나 운영 주체는 여전히 불일치.

## 6. 삼국의 시대구분 방식
### 고구려 (BC 37~AD 668)
| 기준 | 구분 |
|---|---|
| **천도** | 환인시대(주몽~고국천왕) / 환도시대(산상~광개토왕) / 평양시대(장수~보장왕) |
| **발전단계** | 성읍국가(주몽~모본왕) / 연맹왕국(태조왕~고국원왕) / 귀족국가(소수림왕~보장왕) |

### 백제 (천도 기준)
위례성시대 → **한성시대**(근초고왕~, 진씨·해씨 집권) → 웅진(공주)시대 → 사비(부여)시대.

### 신라 — 시대구분 이원 체계 ⭐️ (매우 자주 출제)
| 『삼국사기』(三代) | 『삼국유사』(三古) |
|---|---|
| **상대**(BC57~654): 혁거세~진덕왕 | **상고**(BC57~514): 혁거세~지증왕 |
| **중대**(654~780): 무열왕~혜공왕 | **중고**(514~654): 법흥왕~진덕왕 |
| **하대**(780~935): 선덕왕~경순왕 | **하고**(654~935): 무열왕~경순왕 |

## ❓ 예상 문제
1. 6가야의 이름과 중심지를 쓰고, 전기·후기 맹주국을 밝히시오.
2. 가야가 중앙집권국가로 성장하지 못한 원인을 서술하시오. (율령!)
3. 임나일본부설의 근거와 그 허구성을 3가지 이상 논하시오.
4. 광개토왕비문 해석이 임나일본부설과 어떻게 연결되는지 설명하시오.
5. 『삼국사기』와 『삼국유사』의 신라 시대구분을 비교하시오.

## 🧩 헷갈리기 쉬운 포인트
- **금관가야=전기·김해, 대가야=후기·고령**. 멸망: 금관(법흥왕 532) < 대가야(진흥왕 562).
- 신라 **중대(삼국사기) ≠ 중고(삼국유사)**! 상대·중대·하대 vs 상고·중고·하고 혼동 주의.
- 임나일본부 결정타: **'日本' 국명은 670년경** 등장 → 4세기 사용 불가.
