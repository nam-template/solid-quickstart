## 1. 근대사상 4갈래 ⭐️
> 공통 축: **반봉건(反封建) · 반침략(反帝)** = 자유사상 = 근대화 운동.

## 3. 갑신정변 (1884.12.4-12.6) ⭐️
- 임오군란 이후 대원군 집권 → **청 개입·대원군 납치** → 민씨 외척 집권.
- 청의 **'조선 속방화' 정책 반대**(중국조선상민수륙무역장정).
- **우정국(총판 홍영식) 낙성식 축하연**을 계기로 정변 → **14개조 정강 발표**.
- 신정부: 개화당 요인 + 국왕 종친 연립내각. **청군 개입으로 실패 → 3일 천하**(일본 망명).
- 의의: 가장 적극적 자주 근대화, 근대 민족주의의 이정표.

### 갑신정변 14개조 정강 (김옥균 《갑신일록》 수록)
| 조 | 내용 | 조 | 내용 |
|---|---|---|---|
| ① | 대원군 조속 석방, **조공 폐지** | ⑧ | 순사제도(巡査制度) 실시 |
| ② | **문벌 폐지·인민 평등권**, 능력별 관직 | ⑨ | 혜상공국(惠商公局) 폐지 |
| ③ | **지조법 개혁**, 국가재정 확충 | ⑩ | 유배·금고자 석방 |
| ④ | 내시부 폐지 | ⑪ | 4영을 1영으로, **근위대 설치** |
| ⑤ | 탐관오리 처벌 | ⑫ | **재정 호조로 일원화**, 재무관청 폐지 |
| ⑥ | 환상제도(還上制度) 폐지 | ⑬ | 대신·참찬이 의정소에서 정사 결정 후 왕에 품의 |
| ⑦ | 규장각 폐지 | ⑭ | 육조 외 불필요 관청 폐지 |

## 4. 갑오개혁 (1차) — 1894.7.27-12.17 ⭐️
- **군국기무처 주도, 김홍집 회의총재.**
- 재정 일원화(**탁지아문** 관장), **은본위제**, 조세 금납화, 도량형 정비.
- **방곡령 폐지**(단, **토지제도 개혁은 없음**).
- **6조 → 8아문**(내무·외무·탁지·군무·법무·학무·공무·농상).
- **신분제·연좌제·고문 폐지**, 조혼 금지, 과부 재혼·양자제도 개선, 의복 간소화.
- **과거제·삼사 폐지**, 궁내부 기능 축소.
- **개국기원 사용**(청의 종주권 부인 — 개국기원 503년).

## 5. 을미개혁 (2차·3차 개혁) ⭐️
### 제2차 김홍집·박영효 연립내각 (1894.12.17-1895.7.7)
- **홍범14조 제정**: 고종과 청나라 **절연(絶緣)**, 국왕 친정·법령 준수, **왕비·종친의 정치 간여 배제**, 내정 개혁.
- 일본인 고문관 기용 → 보호국화 기도. **삼국간섭·친러 정책으로 실패.**
- 훈련대 폐지, 중앙 **친위대 2개**, 평양·전주 **진위대** 설치.
- **단발령 공포**(= **을미의병 계기**), 종두법 실시, 우편사 설치, 소학교령(서울 4개 소학교).

## 7. 위정척사운동 ⭐️
- **화서학파의 위정척사론(衛正斥邪論)**: 소중화(小中華)·쇄국. 계보 **이항로 → 김평묵·유중교·최익현 → 유인석**.
- **유중교의 처변삼사(處變三事)**:
  - **거의소청(擧義掃淸)**: 의병을 일으켜 왜적 소탕.
  - **거지수구(去之守舊)**: 국외 망명하여 도맥(성리학) 계승.
  - **자정치명(自靖致命)**: 조용히 자결.
- 유인석의 처변삼사: **도해(蹈海)·자정(自靖)·거의(擧義)**.
- 대응 유형: **거의의병**(김평묵·유중교) / **수구**(간재 전우) / **자정순절**(매천 황현·조병세·이상철).

## 9. 대한제국의 성립 (1897) ⭐️
> 1896년 **제후국 → 황제국**: 연호 사용, 환구단.

- **1895** 을미사변 → **1896** 아관파천(2.11): 갑오경장 내각 붕괴, **독립협회 창립**.
- **1897** 고종 환궁(2.20) → **광무(光武) 연호**(8.16) → 환구단 제작 → **황제 즉위식(10.12) → 대한제국 선포**.
- 정체 대립: **입헌군주제(독립협회) vs 전제군주제(친러정권)** → 고종은 전제군주제 지지.

### 독립협회·만민공동회
- **영은문·독립문**, **만민공동회(1898.3.10)**:
  - 러시아의 **절영도 조차 요구 반대**, 한러은행 철거, 러시아 군사교관·재정고문 철수.
  - 일본 국내 석탄고 기지 철수, 대한제국 자주독립 강화 결의.
- **제2차 만민공동회(1898.3.12)**: 1차 결의안 관철.

### 중추원 개혁 (입헌대의군주제 시도)
- 개혁파 정부 수립(1898.10.12): **박정양·민영환** 중심.
- **최초 의회 설립법 〈중추원 신관제〉(전문 17조) 공포(11.2)**.
  - '상원' 50명(**25명 황제·정부 임명, 25명 투표**).
  - 권한: 입법권·조약비준권·동의권·감사권·**자순권(諮詢權)**·건의권.
- **친러수구파의 방해 공작**: "고종 폐위·박정양 대통령·윤치호 부통령 공화제 수립" 전단 살포.
- 주한일본공사 공작 → 고종에 탄압 권고 → **개혁운동 좌절(12.25).**

### 대한국국제 (1899.8.17) — 전제군주제 (전통 회귀·반동)
| 조 | 요지 |
|---|---|
| 1 | 대한국은 **자주독립 제국** |
| 2 | 정치는 **만세불변의 전제정치** |
| 3 | 대황제는 **무한한 군권** 향유(자립정체) |
| 4 | 군권 침손 행위 = 신민의 도리 상실 |
| 5 | **육해군 통수권**·계엄·해엄 |
| 6 | **입법권·반포·집행**, 대사·특사·감형·복권(자정율례) |
| 7 | 관제·봉급 제정, 칙령 발포(자치행리) |
| 8 | **문무관 임면**·작위·훈장 수여(자선신공) |
| 9 | **선전·강화·조약 체결**, 사신 파견(자견사신) |

- 부속 정책: **원수부 신설**(황실 호위 집중), **국가(國歌) 제정**(에케르트), 산업·광산·철도·홍삼을 **궁내부 내장원**이 관할(수입은 황제 **내탕금**), 보부상을 **상무사**로 개편, **양전사업·지계사업**(토지소유권 증명).

## 10. 러일전쟁과 국권 피탈 ⭐️⭐️
### 러일전쟁 배경
- 친러정권이 러시아에 이권 활양 → **일본 견제**.
- **삼국간섭**(러·프·독): 1895.4 일본 요동반도 청 반환.
- **영일동맹(1902.1)**, 러시아 **용암포 점령(1903.4)** → 정부 **국외 중립 선언(1904.1.22)**(일본 무시).
- 러 군함 선제공격(2.8) → 대러 선전포고(2.10) → **한일의정서(2.23, 토지 수용 용인)** → 한국주차군 편성 → **치안권 박탈**.

### 을사조약 (제2차 한일협약, 준식민지화)
- 친일세력 이식: 이용구 진보회 + 송병준 유신회 → **일진회 통합**.
- **고문 정치**: 제1차 한일협약(1904.8.22) → 재정고문 **메가타**, 외교고문 **스티븐스**.
- 이토(伊藤博文)가 고종에 **을사조약 강요(11.9)**.
  - **반대 3대신**: **한규설·민영기·이하영.**
  - **동의 을사5적**: **이완용·이근택·이지용·박제순·권중현.**
- **통감부 설치(1906.2.1).** → 이후 **한일합방조약(1910.8.22) → 대한제국 멸망.**

### 을사조약 5조 요지
① 일본이 한국의 **외교 관계·사무 감리·지휘** ② 한국은 일본 중개 없이 **국제조약 체결 불가** ③ 서울에 **통감(統監) 1명** 주재, 개항장에 이사관 ④ 기존 조약은 저촉 안 되는 한 유효 ⑤ 일본이 **한국 황실의 안녕·존엄 유지 보증**.

### 정미7조약 (한일신협약, 1907.7.24)
- 배경: **헤이그 특사 사건 → 고종 퇴위**, 대한제국 국권 완전 장악.
- ① 시정 개선 시 **통감의 지도** ② 법령 제정·행정 처분은 **통감 승인** ③ 사법사무를 행정과 구분 ④ 고등관리 임면은 **통감 동의** ⑤ 통감 추천 **일본인 관리 고용** ⑥ 통감 동의 없이 외국인 임명 금지 ⑦ 1904.8.22 고문용빙 협정 제1항 폐지.

## 11. 의병전쟁 상세 & 안중근 ⭐️
### 을미의병 (1895)
- 계기: **명성황후 시해·단발령**. 1896.10 진정. 대표 **유인석**.

### 을사의병 (1904-1906)
- **원용석 의병**(1905.9, 원주 주천) / 정운경·박정수(단양·제천·영주).
- **민종식·안병찬 홍주의병**(1906, 홍주성 점령).
- **최익현 의병**(1906.6, 태인 무성서원 거의) — 교전 회피.
- **신돌석 의병**(1906.4, 영해 거의, 동해안 유격전, 3천여 명) — **평민 의병장**.
- **정환직·정용기 산남의진**(영천·영남).

### 정미의병 (1907-1910)
- 배경: **고종 강제 퇴위·정미7조약·군대 해산(1907.8.1)**. 서울시위대 **박승환 자결**, 시가전 → 원주·강화 진위대 합류.
- 경북 북부: **이강년·신돌석** / 경기: **허위·연기우** / 호남: 기삼연·전해산·김태원·심남일·문태수·이석용 / 함경: **홍범도·차도선**(포수·광산노동자).
- 안중근은 **최재형·이범윤·엄인섭** 등과 의병진 편성, **신아산전투** 수행.

### 서울진공작전 — 13도창의군
- **1908년 초 이인영**(관동의병장) 추대 → 전국 의병 연합(총 48진, 1만여 명).
- **이인영 총대장, 13도창의군 결성, 서울진공작전(1908.1)**.
- **허위**가 300여 명 선발대로 **동대문 밖 30리 지점 전투**.

### 남한대토벌작전 (1909.9-10)
- 일본군 대공세: 동으로 진주·하동, 남으로 목포까지 **그물처럼 포위**, 참빗으로 빗질하듯 촌락 수색·처단(**황현 《매천야록》**).
- 이후 의병은 **남북만주·연해주로 이동 → 1920년대 독립군으로 계승**.

### 안중근
- **평화사상가**, 1909년 의거(하얼빈 이토 저격).
