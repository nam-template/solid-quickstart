## 1. 호족의 사상적 기반 ⭐️
### 풍수도참 (도선)
- 도선이 풍수도참설 체계화(장풍득수). 국토 재편성안으로 발전 → 호족 대두 합리화, **신라 정부 권위 약화**.

### 선종 (禪宗)
- 교종(경전)에 의존하지 않고 **스스로 사색하여 진리 터득** → 개인주의적 성향.
- 이심전심·불립문자·교외별전 → 지방 호족과 결합(중앙 간섭 배격).
- **선종 구산문(九山門)**: 가지산문(보림사)·실상산문·봉림산문·동리산문·사굴산문·성주산문·사자산문·수미산문·희양산문.

## 2. 후삼국 성립
```
신라(쇠퇴) + 후백제(892~936, 견훤) + 후고구려(901~918, 궁예)
```

### 후고구려 — 궁예
- 신라 왕자 출신(헌안왕/경문왕의 아들), 세달사 출가 → 환속.
- 기훤(죽주)→**양길(북원/원주)** 부하 → 자립. 895 명주(강릉) 입성, 896 송악 왕건 귀부.
- **901 후고구려 건국** → 904 국호 **마진**(연호 무태) → 905 **철원 천도**(연호 성책) → 911 국호 **태봉**(연호 수덕만세).
- **패착**: ① 세력기반 미약, ② 초심 상실(고구려 유민 배제·청주세력 중용·미륵신앙 폭정) → 918년 홍유·배현경·신숭겸·복지겸이 **왕건 추대, 궁예 축출**.

### 후백제 — 견훤
- 사벌주(상주) 장군 **아자개의 아들**, 신라 장교 출신.
- 892 무진주(광주) 건국 → 900 완산주(전주) 천도.
- **패착**: ① 927년 경주 함락·**경애왕 살해**(신라인의 반견훤·친고려 정서 유발), ② 호족연합 실패, ③ **왕자의 난**(신검·양검·용검 vs 금강) → 견훤이 고려에 귀순.

### 왕건의 승리 요인
- 송악 호족·예성강 해상세력. **신라에 우호적**, 수취체제 정비(부역·조세 경감), 대호족과 **정략결혼**, 고구려 계승의식.

### 후삼국 통일 과정
- 초기엔 후백제 우세 → **고창(안동) 전투(930)** 승리로 전세 역전 → 신라 경순왕 귀부(935) → 후백제 분열·견훤 귀순 → **일리천(선산) 전투 → 936년 통일**.

## 3. 고려의 시대구분 (이기백 3시기)
| 시기 | 지배세력 | 왕대 |
|---|---|---|
| **전기(10C)** | 호족 | 태조~경종 |
| **중기(11~12C)** | **문벌귀족** | 성종~의종 |
| **후기(13~14C)** | 무인→권문세족→신진사대부 | 명종~공양왕 |

키워드: **호족 → 문벌귀족 → 무인 → 신흥사대부**.

## 4. 고려 사회성격론 ⭐️
### (1) 호족연합정권설 vs 중앙집권제설
- 호족 통제책: **결혼정책 / 사심관제도 / 기인제(其人制)**(상수리제 계승) / 지방관 파견.

### (2) 귀족제 사회설 vs 관료제 사회설
- **귀족제설**: 음서제, 공음전시 → 세습·상속 (유·이·김·최 4가문).
- **관료제설**: 과거제, 막스 베버의 '가산관료제' → 반귀족적.

## 5. 고려 초기 왕권과 호족
### 광종 — 개혁
- **노비안검법(956)**: 호족의 노비 해방 → 호족 경제·군사 기반 약화.
- **과거제(958)**: 신진 인재 등용 → 호족 견제.

### 성종·현종·문종 — 호족의 향리화 ⭐️
- **성종**의 이직개혁: 병부→사병, 창부→사창, 대등→부호장 등 개칭 → 호족을 중앙 통치체제에 편입, **독자성 상실**.
- **현종**의 향리 정원제·공복제: 호장(자삼)·호정(녹삼) 등 복색 구분 → 조직적 통제.
- **문종**의 향리 승진 규정 → 향리직 서열화(9단계: 후단사~호장).

## 6. 고려의 천하관 — 외왕내제 (外王內帝) ⭐️
> 대외적으로는 '왕', 대내적으로는 '황제'를 칭하는 **다원적 천하관**.

| 황제국 용어 | 제후국 용어 |
|---|---|
| 폐하(陛下) | 전하(殿下) |
| 짐(朕) | 여(予)·과인 |
| 절일(節日) | 생일(生日) |
| 태후(太后) | 태비(太妃) |
| 태자(太子) | 세자(世子) |
| 조서(詔書) | 교서(敎書) |

- **연호 사용**: 태조 천수(天授), 광종 광덕·준풍.
- **절일**: 생일을 '절(節)'로 격상 (예: 광종대 이후). '해동천자(海東天子)'(풍입송).
- 조선 세종은 『고려사』 편찬 시 원종 이상은 종(宗)→왕, 절일→생일 등으로 **명분에 맞게 고침**(이실직서 원칙, but 실록대로 기록).

## ❓ 예상 문제
1. 호족의 사상적 기반(풍수도참·선종)이 신라 사회에 끼친 영향을 설명하시오.
2. 궁예와 견훤의 패착(실패 원인)을 각각 서술하시오.
3. 왕건이 후삼국을 통일할 수 있었던 요인을 서술하시오. (고창·일리천 전투 포함)
4. 고려 사회성격론의 두 쟁점(호족연합/중앙집권, 귀족제/관료제)을 설명하시오.
5. 광종·성종의 호족 통제책을 각각 쓰시오.
6. 고려의 '외왕내제' 천하관을 용어 대비를 들어 설명하시오.

## 🧩 헷갈리기 쉬운 포인트
- 후백제 **견훤=상주 아자개의 아들**, 후고구려 **궁예=신라 왕자 출신**.
- 궁예 국호 변천: 후고구려(901)→**마진(904)**→**태봉(911)**, 천도: 송악→**철원(905)**.
- 통일 전투: **고창 전투(930, 전세 역전) → 일리천 전투(936, 통일)**.
- 광종 = **노비안검법(956)·과거제(958)** / 성종 = **향리화(이직개혁)**.
- **외왕내제** = 밖으로는 왕, 안으로는 황제.
