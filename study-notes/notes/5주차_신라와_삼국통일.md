## 1. 신라의 건국 (사로국)
- **6촌 → 6부**: 알천양산촌 등 6촌 → 급량부(이씨)·사량부(정씨)·모량부(손씨)·한기부(배씨)·본피부(최씨)·습비부(설씨).
- 국호 변천: 서나벌·계림 → **신라**(BC 57~AD 935, 56대 992년).
- **삼성(三姓) 교립**: 박(혁거세)·석(탈해)·김(알지) 세 성씨가 교대로 왕위.

## 2. 신라 왕호의 변천 ⭐️ (매우 자주 출제)
```
거서간 → 차차웅 → 이사금 → 마립간 → 왕
```
| 왕호 | 대수 | 의미 |
|---|---|---|
| **거서간(居西干)** | 1대 혁거세 | 군장·귀인 |
| **차차웅(次次雄)** | 2대 남해 | **제사장**(무당) |
| **이사금(尼師今)** | 3대 유리~16대 흘해 | **연장자** |
| **마립간(麻立干)** | 17대 내물~22대 지증 | 간(干)의 우두머리(대군장) |
| **왕(王)** | 22대 지증왕부터 | 중국식 왕호 |

> 왕호가 **제사장(차차웅)→연장자(이사금)→대군장(마립간)→왕**으로 변한 것은 왕권 강화 과정을 반영.

## 3. 마립간 시대의 연맹왕국
- 17대 **내물마립간**: 김씨 왕위 세습 확립, 381년 전진에 사신, 399년 고구려에 원병 요청.
- 반고구려 정책: 눌지(나제동맹)·자비(축성)·소지(고구려 축출)·지증(중국식 왕호, 국호 '신라' 확정).

## 4. 중앙집권적 귀족국가 ⭐️
### 법흥왕 (재위 514~540) — 체제 정비 ('중고'의 시작)
- 517 병부 설치 → 520 **율령 반포·관복 제정** → 527 **불교 공인(이차돈 순교)** → 531 상대등 설치 → 532 **금관가야 정복** → 536 연호 **건원(建元)** 사용.

### 진흥왕 (재위 540~576) — 대외 정복
- **순수비**: 창녕비(561)·북한산비·황초령비·마운령비(568)·단양적성비(545).
- 553 한강 유역 장악 → 562 대가야 복속.
- 545 **『국사』 편찬**(거칠부), 576 **화랑도** 창설, 연호 개국·대창·홍제.

## 5. 나당동맹과 백제 멸망
### 배경
- 642년 **대야성 전투**(백제가 신라 서부 장악) → 신라 위기.
- **김춘추의 외교**: 고구려·왜에 실패 후 당과 **나당동맹(648)**. 조건: 당 연호 사용, 김인문의 숙위, 조공. 당은 고구려 침략 실패로 공격 대상을 백제로 전환.

### 백제 멸망 (660)
- 소정방 13만(백강) + 김유신 5만(탄현) → 백제 항복.
- 계백의 황산벌 전투, 낙화암 전설(궁녀 3천은 과장, 남효온은 300명 기록).

### 백제 부흥운동
- 인물: 복신·도침·흑치상지·지수신, 왕자 부여풍.
- 근거지: 임존성(예산)·주류성(서천). **백강 전투**.
- 실패 원인: 지도부 내분 / 조직·정보력 빈약 / 신라의 분열 정책.

## 6. 고구려 멸망과 나당전쟁
### 고구려 멸망 (668)
- **연개소문 사망(665) 후 내분**: 남생(당 투항)·남산·남건의 권력 다툼, 연정토(신라 투항).
- 당 이세적이 남생을 앞세워 공격 → 668년 평양성 함락, 보장왕 항복.

### 고구려 부흥운동
- 검모잠(궁모성), 왕자 **안승**(신라 투항, 금마저 정착), 고연무 + 신라 설오유.

### 나당전쟁 (670.3~676.11) ⭐️
- 당이 한반도 전체를 지배하려 하자 신라가 반격.
- **675년 매소성 전투** + **676년 기벌포 전투** 승리 → 당 축출, **삼국통일 완성**.

---

## 7. 삼국통일의 한계와 의의
| 한계 | 의의 |
|---|---|
| 외세(당) 의존 | 김춘추·김유신의 자주적 결전 의지 |
| 영토 축소(대동강~원산만) | 나당전쟁으로 당 축출 |
| **불완전 통일**(발해·후백제 건국) | 백제·고구려 유민 포용 노력 |
| 북한: '통일신라' 아닌 **후기신라·남북국시대** | 단일민족·민족문화의 기반 |

## ❓ 예상 문제
1. 신라 왕호 변천 5단계를 순서대로 쓰고 각 의미를 설명하시오.
2. 법흥왕과 진흥왕의 중앙집권화·정복 정책을 각각 서술하시오.
3. 나당동맹의 체결 배경과 조건을 설명하시오.
4. 백제·고구려 멸망의 직접 원인을 각각 쓰시오. (의자왕 외교실패 / 연개소문 사후 내분)
5. 나당전쟁의 두 결정적 전투를 쓰고 의의를 서술하시오.
6. 신라 삼국통일의 한계와 의의를 각각 3가지씩 논하시오.

## 🧩 헷갈리기 쉬운 포인트
- **법흥왕=율령·불교공인·금관가야 정복 / 진흥왕=순수비·한강·대가야·국사·화랑도.**
- 매소성(675)·기벌포(676) = **나당전쟁** 승리 전투 (백제·고구려 멸망 전투와 구분).
- 통일 완성 연도 **676년**(당 축출) ≠ 고구려 멸망 668년.
- 안승은 **고구려** 부흥운동 인물(신라에 투항, 금마저).
