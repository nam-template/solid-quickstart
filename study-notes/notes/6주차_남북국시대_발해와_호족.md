## 🎯 한눈에 보기
① **남북국시대론**(신라+발해)의 개념과 반론, ② 신라 **중대**의 성립(무열왕계 전제왕권), ③ **발해**의 건국·발전·멸망, ④ 신라 **하대**의 성립과 **호족의 등장**.

## 1. 남북국시대론 ⭐️
> 발해사를 한국사에 포함시켜, '통일신라' 대신 **신라(남국)+발해(북국)**를 아우르는 '남북국시대'로 부르자는 논의.

### 근거
- 『삼국사기』·최치원 「사북국불허거상표」에서 발해를 **'북국(北國)'**으로 호칭.
- 897년 사신 간 윗자리 다툼, 872·906년 유학생 간 빈공과 수석 다툼(양국 대등 인식).

### 주창자
- **유득공 『발해고』(1784)** — 신라·발해를 남북국으로 최초 인식, 고려가 발해사 안 쓴 것 비판. (조선 후기 실학자!)
- 김정호 『대동지지』(1864), 일제하 장도빈·황의돈·권덕규, 남한의 **이우성**이 적극 제기.

### 반론
- 발해는 **말갈족** 국가다(중국·러시아) / 발해·신라는 동족의식 없었다(이용범) / 하나의 통일체에서 갈라진 게 아니다(북한).

## 2. 신라 중대의 성립 (전제왕권)
- **무열왕(654)~혜공왕(780), 126년** = 中代. 진골 출신 무열왕계.
- **동륜계 vs 사륜계 갈등**: 진흥왕 → 동륜(→진평→선덕여왕) / 사륜(진지왕→김용춘→**김춘추**).
- **김춘추 + 김유신(신김씨)** 결합 → 무열왕계 전제왕권 성립.

### 중대 사회의 성격
1. 한식(漢式) 왕명 채택 → 보편성 확보.
2. 유교 정치이념·율령체제 정비, **6두품 진출·진골 위축**.
3. **전제왕권 확립, 태자 임명**.
4. 위민(爲民)정책 → 하층민 지위 향상.
5. 유·불·도 확산, 종파불교 발달.

## 3. 북국 발해 (698~926) ⭐️
### 건국
- 고구려 멸망 후 유민 강제 이주(영주). 거란(이진충)의 난을 틈타 탈출.
- **걸걸중상·대조영 부자** (속말말갈 추장, 고구려 별종/고구려 장수 [당서]).
- **천문령 전투** 승리(당 이해고 격파) → **진국(震國)** 건국(698).

### 발전 — '해동성국'
- **2대 무왕**: 732년 당의 등주 공격(대당 강경).
- **3대 문왕**: 전륜성왕, 체제 정비. (정효공주 무덤 벽화)
- **10대 선왕(대인수)** 대에 전성기 → '해동성국'.

### 멸망
- 907년 요(거란) 건국 → 925년 발해 공격 → 926년 15대 대인선 항복.
- 유민 부흥운동: 동단국·정안국·흥요국·대발해국.
- **고구려 문화 계승** → 고려로 이어짐.

## 4. 신라 하대의 성립
### 중대 전제왕권의 몰락
- 신문왕: 김흠돌의 난 진압, **녹읍 폐지·관료전 지급**, 달구벌 천도 실패.
- 경덕왕: 한화정책(전제왕권 회복 시도) → 실패.
- **혜공왕 피살**(12차례 반란) → **무열왕계 몰락**, 선덕왕 즉위 → **下代 도래**.

### 원성왕 즉위
- 김주원(무열왕 6세손) vs **김경신(내물왕 12세손)** 왕위 쟁탈 → **원성왕(김경신)** 즉위.
- 하대 = 귀족연립적 성격: 집사부 시중 약화, **상대등 권한 강화**.
- 진골 귀족 분열 → **사병 조직**, 정권 쟁탈 → **155년간 20명 왕 교체**.

## 5. 호족의 등장 ⭐️
### 배경
1. **원성왕계 분열**: 인겸계vs예영계, 헌정계vs균정계 → 치열한 왕위 쟁탈전.
2. **잦은 자연재해와 농민 유리**: 흉년·기근 → 진성여왕대 **원종·애노의 봉기**(889, 사벌주), 초적(적고적) 등장.
3. **국가재정 파탄·중앙통치력 와해**: 골품제 모순(6두품 반발: 최치원·최언위·최승우), 김헌창(822)·장보고(846) 반란, 촌주 출신 호족의 성장.

### 호족의 유형 (5가지) ⭐️
| 유형 | 대표 인물 |
|---|---|
| **① 낙향귀족** | 김주원(강릉, 명주군왕)과 후손 김순식 |
| **② 지방관 출신** | 견훤(하급장교+해상), 김인광 |
| **③ 군진세력** | **장보고**(청해진) |
| **④ 해상세력** | 왕융(왕건 父), 나주 오씨 |
| **⑤ 재지세력(촌주층)** | 양길(북원경/원주) — *7주차에 이어짐* |

### 장보고 (군진세력) ⭐️
- 궁복(활 잘 쏘는 사람), 신분 극복 위해 도당(渡唐) → 무령군 복무.
- 828년(흥덕왕 3) 귀국 → **청해진(완도) 대사** → 해적 소탕, 동북아 해상무역 허브.
- 산둥 적산촌에 **법화원** 건립.
- 왕위 쟁탈전 개입: 김우징(신무왕) 옹립 → 감의군사. 딸을 왕비로 들이려다 진골 반대 → **846년 염장에게 피살**, 851년 청해진 폐쇄.

## ❓ 예상 문제
1. 남북국시대론의 개념과 최초 주창자(유득공)를 쓰고, 반론을 서술하시오.
2. 신라 중대 사회의 성격을 4가지 이상 서술하시오.
3. 발해의 건국 과정(대조영·천문령)과 '해동성국'의 의미를 설명하시오.
4. 신라 하대 왕위 쟁탈전(원성왕 즉위)과 호족 등장의 상관관계를 논하시오.
5. 호족의 5가지 유형을 대표 인물과 함께 쓰시오.
6. 장보고의 활동과 몰락 과정을 서술하시오.

## 🧩 헷갈리기 쉬운 포인트
- **남북국시대론 최초 주창 = 유득공 『발해고』(1784)** (조선 후기 실학자).
- 발해 건국지 = **천문령 전투** 승리 후 진국(震國) → 발해.
- 신라 **중대(무열왕계 전제왕권)** vs **하대(원성왕계, 귀족연립·호족)**.
- 하대에는 시중↓·**상대등↑** (중대와 반대).
