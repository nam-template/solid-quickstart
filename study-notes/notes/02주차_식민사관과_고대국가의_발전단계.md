## 1. 식민사관 (植民史觀)
일제가 식민지배를 정당화하려고 만든 역사관. 본질 → 비판 대상 → 관련 시대사로 정리.

| 식민사관 | 세부 논리 | 극복(비판) 논리 | 주로 다루는 시대 |
|---|---|---|---|
| **타율성론** | 반도적 성격론, 만선사관, 사대주의론 | 자주성·민족주의 | 고대사·고려사 |
| **일선동조론** | 일선동역론, 임나일본부설, 정한론 | 삼한삼국분국설 | 고대사 |
| **정체성론** | 봉건제 결여론, 중세부재론, 식민통치 미화론 | 자본주의 맹아론(실학) | 조선·근대사 |
| **당파성론** | 당쟁·분열 강조 | 붕당론(정치사로 재해석) | 조선시대사 |

**시험 포인트:** 각 식민사관 ↔ 극복논리 ↔ 시대를 짝짓는 문제가 잘 나온다.
예) 정체성론 → (극복) 자본주의 맹아론 / 타율성론 → (극복) 자주성·민족주의.

## 2. 민족의 뿌리 — "우리는 단일민족인가?"
- **흥수아이**(청주 두루봉동굴, 약 4만 년 전) — 구석기 인골.
- 신석기 인골: 통영 연대도 패총, 여수 안도 패총(남녀 합장).
- **2017 UNIST 게놈 분석**: 현대 한국인 = 베트남 원주민 + 러시아 악마문동굴 고대인(7,700년 전) 융합에 가장 가까움 → 유전적으로는 **다양한 기원**.
- 그럼에도 위기 시 단합(의병·국채보상운동), 혈연·지연·학연 공동체 의식으로 '단일민족' 관념 유지.

## 3. 고대국가 발전 4단계 ⭐️ (가장 중요)

```
성읍국가 → 소연맹국 → 연맹왕국 → 중앙집권적 귀족국가
(군장사회)  (소국연맹체)  (部체제)
```

| 단계 | 해당 국가 | 정치·종교 | 통치 특징 | 신앙/제천 |
|---|---|---|---|---|
| **성읍국가** | (고)조선 | 제정일치(단군왕검) | 이주민+토착민 | 건국신화 |
| **소연맹국** | 마한·진한·변한(삼한) | 제정분리(소도) | 국읍·별읍 | 시조묘·지모신 |
| **연맹왕국** | 부여·고구려·백제·신라·가야 | 귀족연합 | 사출도·5부·귀족회의 | 영고·동맹·무천 |
| **중앙집권적 귀족국가** | 고구려·백제·신라 | 왕권강화 | **율령·불교공인**·부자상속·태자제 | 유교·불교 |

### 핵심 대비 개념
- **제정일치(성읍국가)** vs **제정분리(소연맹국)**: 소연맹국 단계에서 제사장 '천군(天君)'을 따로 임명 → 종교·정치 분리. 별읍 = **소도(蘇塗)**(신성지역, 도망자도 잡지 못함).
- **귀족회의**: 제가회의(부여·고구려) / 좌평회의=정사암(백제) / 화백회의=남당(신라).
- **제천행사**: 영고(부여) / 동맹(고구려) / 무천(동예).
- **중앙집권화의 2대 지표 = 율령 반포 + 불교 공인.**
  - 율령: 관습법 대체 → 귀족을 왕권에 흡수, 신분제(신라 골품제)·관등제 정비.
  - 불교: 왕권 중심 지배 이념(전륜성왕 사상), 윤회전생으로 골품 특권 정당화. 신라만 **이차돈 순교(527, 법흥왕)** → 535년 공인.

## 4. 고조선 (성읍국가)
- 건국신화: 환웅족(청동기) + 곰족(신석기) → 제정일치(단군왕검), 천강·난생 설화.
- **삼조선**: 전조선(단군조선·기자조선) + 후조선(위만조선).
- **기자조선**: 기자가 은(殷)에서 망명, 팔조금법 제정 → 일제는 이를 근거로 '타율성론' 주장(중국인이 세운 식민지·분국).
- **위만조선(BC 194~108, 3대 87년)**:
  - 위만이 연나라 출신이나 "상투 틀고 조선옷" 착용 기록 → **조선인·연합정권**으로 해석.
  - 국호 '조선' 유지, 토착세력 관직 '조선상(朝鮮相)' 존재 → 이주+토착 연합정권.
  - 한 무제의 공격으로 멸망 → **한사군** 설치.

## 5. 부여 (연맹왕국 단계에서 멸망) ⭐️
> "왜 부여는 중앙집권 국가로 성장하지 못하고 멸망했는가?"가 핵심 논점.

- **건국신화 2가지**: ① 천제의 아들 해모수 / ② 고리국(탁리국)에서 알로 태어난 동명(東明).
- **정치체제**: 사출도(四出道) — 왕도 사방으로 마가·우가·구가·저가가 통치. 왕은 가(加)들의 대표일 뿐 초월적 권력 ✕. 흉년이면 왕에게 책임을 물어 교체·살해.
- **우제점(牛蹄占)**: 소 발굽으로 길흉 점침 → 왕의 제사장적 성격.
- **성장 못한 이유**: 율령 없음 / 불교 공인·정복군주·역사서 없음 / 공동체적 전통 잔존 / 외침 대응 실패.
- **멸망 과정**: 285년 선비 모용씨 침입 → 346년 전연 공격 → 고구려 복속 → 494년(문자왕 3) 최종 소멸.

### 부여의 위상 (한국사에서 중요한 이유)
부여에서 갈라져 나온 나라들:
- **동부여** (해부루·금와·대소, 410년 광개토왕이 병합)
- **졸본부여 = 고구려** (해모수 → 주몽)
- **남부여 = 백제** (성왕이 사비 천도 후 국호를 '남부여'로 개칭)

## ❓ 예상 문제
1. 식민사관 4가지를 쓰고 각각의 극복 논리를 연결하시오.
2. 고대국가 발전 4단계를 순서대로 쓰고, 각 단계의 대표 국가·정치형태를 서술하시오.
3. 제정일치와 제정분리의 차이를 소도(蘇塗)와 관련지어 설명하시오.
4. 중앙집권적 귀족국가의 두 가지 지표(율령·불교)의 의미를 서술하시오.
5. 부여가 연맹왕국 단계에서 멸망한 원인을 3가지 이상 제시하시오.
6. 부여에서 파생된 나라 세 곳을 들고 관계를 설명하시오. (동부여·고구려·백제)

## 🧩 헷갈리기 쉬운 포인트
- **사출도 = 부여** (5부는 고구려, 6부는 신라). 숫자로 구분!
- 위만조선은 '중국 식민정권'이 아니라 **이주+토착 연합정권**으로 보는 것이 통설.
- 제천행사: **영**고=부여, **동**맹=고구려, **무**천=동예 (앞 글자로 암기).
